# 約好 AI MVP v3 線上教學腳本

建議時間：15 到 20 分鐘。

## 1. 看一週預約

請客戶打開 `01 一週預約表`。

說明：

- 本週、下週、下下週可以切換
- 每位美甲師會看到自己的預約
- 已完成的預約會用不同顏色標示

## 2. 新增現場客

請客戶打開 `02 現場新增`。

示範：

1. 選美甲師
2. 選服務
3. 選日期與開始時間
4. 填客人姓名或電話
5. 到表格下方選 `執行現場新增`

## 3. 修改或取消預約

請客戶打開 `03 修改預約`。

示範：

1. 輸入預約編號
2. 執行 `載入預約`
3. 確認資料正確
4. 選擇 `修改時間`、`延長時間` 或 `取消預約`

## 4. 查詢預約

請客戶打開 `04 預約查詢`。

說明：

- 可選月份
- 可選狀態
- 預約會依服務日期和開始時間排序

## 5. LINE 測試

請客戶用 LINE 傳：

```text
預約
```

確認可以完成：

- 預約
- 取消預約
- 詢問服務與價格
