# 店家手機維護指南 MVP v3

## 每天最常看

打開 `01 一週預約表`。

可以選：

- 本週
- 下週
- 下下週

每位美甲師會看到自己一整週的預約。

## 新增現場客

打開 `02 現場新增`。

1. 選美甲師
2. 選服務
3. 選日期
4. 選開始時間
5. 客人姓名、電話可填可不填
6. 到表格下方，把執行指令選成 `執行現場新增`

如果是不在營業時間或美甲師休假日，系統會提醒，確認後才會執行。

## 修改預約

打開 `03 修改預約`。

1. 輸入預約編號
2. 執行 `載入預約`
3. 確認載入的是正確客人
4. 填新的日期或時間
5. 執行 `修改時間`

## 延長時間

打開 `03 修改預約`。

1. 輸入預約編號
2. 執行 `載入預約`
3. 填延長分鐘數，例如 `30`
4. 執行 `延長時間`

## 取消預約

打開 `03 修改預約`。

1. 輸入預約編號
2. 執行 `載入預約`
3. 確認客人資料正確
4. 執行 `取消預約`

## 查詢單月預約

打開 `04 預約查詢`。

選月份和狀態後，系統會依實際服務日期和開始時間排序。
